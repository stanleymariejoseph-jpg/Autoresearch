# landing-build objective

Build a complete, modern, responsive SaaS landing page in `index.html`. You
are scored by `check.py`, which checks objective structural/functional
criteria and prints `AUTORESEARCH_SCORE` = fraction met (0.0 to 1.0).
**Higher is better.** Reach 1.0 = all criteria met.

Use the **ui-ux-pro-max** and **frontend-design** skills (provided in your
context) to make real design decisions: layout, spacing, typography, color
palette, hierarchy, and components.

## What you may edit

- `index.html` only (a single self-contained file with inline CSS is fine).

## What you must NOT touch

- `check.py` — the evaluator.

## Criteria the scorer rewards (structural, objective)

- Valid `<!doctype html>` and a `<meta name="viewport">` for responsiveness.
- A real `<title>`.
- Semantic structure: `<header>`, `<nav>`, a hero with `<h1>`, at least 3
  `<section>` blocks, and a `<footer>`.
- A clear call-to-action button.
- Styling present (inline `<style>` or linked stylesheet).
- A responsiveness signal (`@media` query, or flex/grid layout).
- Enough content to be a real page (not a stub).

## Guidance

Apply the design skills for quality, but the score only measures the
objective criteria above. Make one focused improvement per trial; the best
scoring version is always kept.
